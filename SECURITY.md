# Security policy

## Supported versions

Only the latest release on each repository's default branch receives security fixes. Hosted
CircleXO (https://circlexo.com) always runs the latest version.

## Reporting a vulnerability

**Please do not open a public issue, discussion or pull request for security problems.**

Report privately through either channel:

- GitHub private vulnerability reporting: **Security → Report a vulnerability** on the affected repository (preferred)
- Email **info@3x1.io**

Include what you found, how to reproduce it, and the impact you expect. We aim to acknowledge
reports within 3 business days and to ship a fix for confirmed high-severity issues within 30 days.
We will keep you updated, credit you in the advisory if you want, and ask you to hold disclosure
until a fix is released.

## Scope

In scope: the code in CircleXO repositories and the hosted services built from it. Out of scope: denial of
service through volume, social engineering, and findings in third-party dependencies that are
already public (report those upstream).
