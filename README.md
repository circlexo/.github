# circlexo/.github

Organization-wide files for [CircleXO](https://github.com/circlexo).

- [`profile/README.md`](profile/README.md) is the organization profile shown on
  [github.com/circlexo](https://github.com/circlexo).
- The community health files here are the defaults for every CircleXO repository that does not
  ship its own: [`CONTRIBUTING.md`](CONTRIBUTING.md), [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md),
  [`SECURITY.md`](SECURITY.md), the [issue forms](.github/ISSUE_TEMPLATE) and the
  [pull request template](.github/PULL_REQUEST_TEMPLATE.md).

Questions about CircleXO go to [Discussions](https://github.com/circlexo/.github/discussions).
